# 安装包说明
## MAC包
arm64：给 Apple Silicon 芯片使用，也就是 M1、M2、M3、M4 系列 MacBook。

x64：给 Intel 芯片的 Mac 使用，也就是较老的 Intel 版 MacBook。
## Windows包
x64：给 64 位 Windows 使用，现在绝大多数 Windows 10/11 电脑都是这个，优先发这个。

ia32：32 位 Windows 使用，主要兼容很老的电脑。
